## About me

I’m a software engineer focused on building practical systems for real-world operations. My work is usually at the intersection of **backend engineering, internal tools, desktop applications, automation, integrations and data**.

I like taking processes that depend on spreadsheets, manual communication or disconnected tools and turning them into software that is easier to operate, measure and scale.

- 🧠 Building automation and AI-assisted workflows
- 🖥️ Developing web and desktop applications
- 🔌 Integrating APIs, services and internal systems
- 🗄️ Working with relational databases and operational data
- 👁️ Exploring computer vision and recognition systems
- ⚙️ Interested in developer tooling, orchestration and infrastructure
